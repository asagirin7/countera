English

Questions, bug reports and requests are welcome. Please open an issue on GitHub:

github.com/asagirin7/countera/issues

Tips

  • Add a widget: long-press the Home Screen → Edit → Add Widget → Countera. The widget settings open right away.
  • Shortcuts: search for “Countera” in the Shortcuts app to find all actions.
  • Dynamic Island: the first time, allow Live Activities for Countera when asked (Settings → Countera → Live Activities).

日本語

質問・不具合の報告・要望は、GitHub の Issue でお寄せください。

github.com/asagirin7/countera/issues

使い方のヒント

  • ウィジェットを置く: ホーム画面を長押し →「編集」→「ウィジェットを追加」→ Countera。置くとすぐ設定が開きます。
  • ショートカット: ショートカットのアプリで「Countera」を検索すると、すべてのアクションが出ます。
  • ダイナミックアイランド: 初回に聞かれたら、ライブアクティビティを許可してください(設定 → Countera → ライブアクティビティ)。
